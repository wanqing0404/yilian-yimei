# 医联好美 · 原生微信小程序

原生 WXML / WXSS / JavaScript，无 npm 依赖。配套本机运营后台位于相邻的 `yilian-haomei-admin` 目录。

## 预览与启动

在上一级交付目录运行 `python3 launch_demo.py`，或双击 `启动医联好美.command`。Python 3.8+ 即可。

- 小程序：http://127.0.0.1:8765/preview/?page=home
- 我的：http://127.0.0.1:8765/preview/?page=profile
- 会员中心：http://127.0.0.1:8765/preview/?page=member-center
- 积分秒杀：http://127.0.0.1:8765/preview/?page=point-flash
- 运营后台：http://127.0.0.1:8766/admin/（admin / demo2026）

微信开发者工具导入此目录，并配置自己的 AppID。`preview/` 是浏览器预览适配器，不参与微信打包；导入配置已设置忽略预览、原始图标和旧素材。

## 页面与入口

底部导航：首页、分类、服务、会员、我的。

首页五个入口：社群拼团、社群秒杀、积分商城、术后护理、领券中心。另有积分秒杀、每日签到、邀请礼遇、订单抽奖入口。

“我的订单”入口：待支付、购物车、待使用、售后/退款。购物车改为普通页面，通过个人页或商品详情进入。待评价与商品评论按最新要求移除。

底部“会员”或个人页会员卡进入会员中心：显示当前积分、等级、可领/已领/已用福利、升级差额、成长旅程、积分商城入口与本季推荐。会员规则由后台配置，初始等级门槛是演示值。

医生详情仅浏览，含医生认证资料展示，不含预约按钮。分类“全部”固定，其他分类横向滚动，支持左右切换，不包含口腔美容。

## 后台联动

`utils/remote.js` 连接本机API，进入页面或刷新后获取配置。价格、分类、拼团资格、秒杀、礼券、积分商城、会员、签到、阶段奖励、抽奖凭证与核销状态均已连接。数据保存到后端SQLite。积分商城可配置积分加现金；积分秒杀始终为纯积分。消费奖励积分规则初始为关闭，确认比例后可由运营开启。

微信真实登录、微信支付/退款、云端部署及实物履约未接入。当前为固定顾客身份的本地演示，具体边界见后台README。真机无法直接访问电脑127.0.0.1，需要替换为可访问的HTTPS测试域名，并配置微信合法域名。
