## 联动方式

小程序使用 `utils/remote.js` 读取本机 API，进入页面或刷新后获取最新配置。商品与分类、拼团、秒杀、优惠券、换购、医生、门店及福利规则已联通。首页横向福利入口进入签到、邀请活动、订单凭证抽奖。

前台新生成的 DEMO 订单同步到后台后默认待付款；后台模拟付款、核销和退款的状态在顾客端下次进入页面/刷新时同步。历史订单金额保留订单快照，不随商品调价回写。当前演示顾客是 `demo-user / 19900000000`，不是微信真实登录身份。

## 核心规则

- **新客**：没有任何历史核销记录；核销过再退款仍算老客。发起人、参团人分别设置资格。
- **活动**：按受邀新客完成核销的唯一顾客数累计；退款后该订单不计有效进度。未达标不能领取，每阶段只能领一次。活动编号相同视为同一领取周期，更换编号创建新周期；目标统计仍使用演示邀请记录。当前没有按活动日期范围过滤历史核销。
- **价格**：整数分保存；销售价不高于划线价，会员价不高于销售价，配置了上下限时必须符合。初始价格均为先前页面示例，未代表机构确认价格。关闭“展示示例价格”后，未确认商品会显示价格待确认并禁止购买。
- **抽奖**：开启截图规则时必须人工审核通过。每个手机号限次，0为不限；权重是相对概率，库存为0的奖品不再被抽中。凭证后续被撤销，对应记录失效、积分奖励冲回、库存恢复；失效记录仍占用已使用的抽奖次数。实物礼品只登记，待人工履约。
- **签到**：北京时间每天一次，重复或同时请求只发一次积分。周期可以连续或累计，完成周期后循环。

## 存储与边界

`data/operations.sqlite3` 为SQLite本地数据库；`data/uploads/` 保存顾客凭证截图，仅登录管理员可读取。备份时请先停止服务，或使用SQLite在线备份。压缩源码包不包含登录会话、操作数据库和顾客截图；首次运行会从 `data/seed.json` 初始化示例。

当前是单机演示：固定管理员、固定顾客身份、无真实微信登录/手机号验证、无真实支付退款、无跨用户实时拼团、无自动截图识别。会员充值、真实预约/诊疗计划、实物礼品履约未接入该后台；积分商城扣分和优惠券领取已迁到服务端。旧设备端兑换记录归档保留在设备的 legacyLocalRedemptions 字段，不自动认定为服务端订单。

正式上线需接入微信身份、支付回调、服务端下单/拼团/库存与积分账本、管理员角色权限、HTTPS域名和云数据库/备份。本机服务默认仅监听127.0.0.1；演示账号不得用于公网部署。管理员可以通过 `ADMIN_USER` 和 `ADMIN_PASSWORD` 环境变量配置；非本机监听时默认密码会被拒绝。

开发者工具联调时，`utils/remote.js` 中的 `BASE` 指向本机服务；真机请替换为可访问的测试HTTPS域名并在微信后台配置合法域名。127.0.0.1在手机上指向手机自身。

## 会员体系与积分秒杀

- 会员中心展示当前BP积分、等级、福利领取与使用记录、升级差额、会员旅程、积分商城入口、本季热推。
- 后台「会员体系」支持累计已核销金额、累计实付金额、独立成长值三种升级口径；等级名称、门槛、成长系数、福利类型/季度次数/适用等级与热推商品均可配置。初始会员门槛是演示值，需按实际制度确认。
- 福利按自然季度领取，礼券进入顾客券包；运营登记已使用后，顾客端的已用次数同步更新。升级口径按当前有效订单统计，退款会减少消费累计值，等级可能随之变化；本季已领福利保留记录直至到期。
- 「积分秒杀日」支持每周或每月排期、开始时间、时长、纯积分价格、本场库存、单品限购、手机号场次限购和累计签到门槛。每月日期支持1—28日。默认草稿未启用，确认后由运营开启。
- 秒杀库存按每场独立计算，扣积分与扣库存置于同一数据库事务，库存不足或积分不足不生成兑换。调整排期会改变场次编号；已有兑换保留原场次，不迁移占用新场次库存。
- 普通积分商城可配置积分加现金，提交时扣减演示积分并生成现金待付款订单；取消或退款时自动退回积分。现金换购订单不重复产生消费奖励积分。
- 「签到与积分」中增加消费积分发放：默认关闭，可选择付款后/核销后发放及每元奖励积分，退款时自动冲回，不追溯规则开启前已经完成的订单。
- 会员余额、签到、阶段奖励、抽奖、积分商城和积分秒杀共用服务端积分账本。规则撤销/退款冲回时，若积分已用掉，服务端可能出现负余额，需要运营对账处理，不通过将余额截为0掩盖差额。

## 最新入口调整

首页入口名称：社群拼团、社群秒杀、积分商城、术后护理、领券中心。底部导航为首页、分类、服务、会员、我的。购物车从个人页订单区进入。待评价与商品评论模块已移除，旧演示评论保留在本地数据库作历史归档，管理和顾客接口不再提供评论功能。

## 已验证

已通过隔离数据库接口验证：登录与来源校验、价格边界、历史核销身份、签到并发防重、阶段奖励防重、抽奖凭证审核/限次/撤销冲回、积分商城现金订单取消退分、会员领取/使用/升级差额、积分秒杀并发库存与跨周/月排期、消费积分发放与退款冲回。浏览器中验证了配置保存、签到加分、活动点亮、会员领取，以及新版个人页与购物车入口。正式微信支付、真机与多管理员并发编辑未验证。

## 商品删除与回收站

在「商品与价格」点击「删除商品」，确认商品名称后移至回收站。本机小程序重新进入或刷新后不再展示该商品，历史订单和成交金额保持原快照。筛选「回收站」可恢复商品；恢复后默认下架，需要核对后再上架。关联拼团或秒杀的商品须先取消活动关联。删除和恢复均记录到操作日志，接口要求管理员登录。公网独立Demo使用目录快照，不随本机操作自动变更。
